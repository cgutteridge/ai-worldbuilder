# Prompt pack v1 — feature design (pilot)

Frozen brief for **attempt 1 (cold)** bake-off rounds. Repair attempts attach a short repair brief; do not edit this file mid-pilot (bump to `v2` instead). Fairness / pad / ghost / ownership notes: [FAIRNESS.md](FAIRNESS.md).

## Task

Feature design from evidence for the focus building(s) in cell **(48, -44)** — SUSU / south Library Square. Apply is allowed. Restore the 3×3 ghost baseline before you start.

## Rules

1. Fill an evidence table from real sources (OSM footprint, lidar heights, streetlevel openings, aerial roof/greeblies). **Do not** treat a previous Minecraft build as evidence.
2. Design massing, openings, roof, and street-scale greeblies from that table.
3. Shell-only plans are incomplete: list greeblies or write `greeblies: none visible`.
4. Prefer Minecraft-readable massing over jagged 1:1 OSM walls.

## Outputs expected before interview

- Evidence table (in script docstring or notes)
- Build script / plan ready to apply
- Apply completed (or dry-run + explicit block if apply impossible)
